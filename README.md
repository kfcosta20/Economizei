# Economizei
Projeto acadêmico de uma plataforma promoções

## Sobre o projeto
Projeto acadêmico de desenvolvimento web voltado à
divulgação e organização de ofertas e oportunidades
de economia para consumidores.

## Status
Em desenvolvimento.

## Objetivo
Criar uma plataforma que facilite a busca por ofertas,
reunindo produtos e oportunidades de economia em um só lugar.

## Tecnologias utilizadas
- Java
- PHP
- SQL

## Próximas etapas
- Aprimorar a interface do site.
- Implementar novas funcionalidades.
- Melhorar a organização e navegação da plataforma.
